Follow-up to our reply of today, with the two things we promised.

1. NEW BUILD
Build __BUILD__ is attached to version 1.0 and replaces build 51. It adds the
blocking mechanism that was missing. Blocking is now in all four one-to-one
conversations in the app: the order chat, and the ride, cleaning and car-wash
chats. Reporting was already in build 51 and is unchanged.

It also fixes two crashes we found ourselves on a physical iPhone, and we
would rather tell you about them than let you find them. (1) Our Google Maps
key was not reaching the release binary, so the first map created terminated
the app with GMSServicesException; the app opens the order-tracking map as soon
as a courier is assigned, so placing a test order would have crashed build 51
for you. (2) Info.plist lacked NSFaceIDUsageDescription, so signing in with
Face ID terminated the app. Both are fixed; the release job now refuses to
produce a binary without the Maps key, and an automated sweep opens every home
tile and signs in with all three roles before any build is uploaded. We
reproduced both crashes, read the crash reports, fixed the causes and verified
the fixes before submitting this build.
