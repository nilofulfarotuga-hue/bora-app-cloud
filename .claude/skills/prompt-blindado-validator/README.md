# prompt-blindado-validator

Validador de governança invocado pelo **CEO-AI** no início de cada tarefa.
Verifica que o prompt respeita as regras do Bora App (MODO PROTECÇÃO TOTAL,
business_rules, git push, /ctx, admin, zonas protegidas). Se encontrar
violações, **reporta e pára** — não executa.

Ver `SKILL.md` para o checklist completo de validação.
